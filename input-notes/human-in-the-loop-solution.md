我设计了一种 Human‑in‑the‑loop 解决方案：hook + md 文档编辑。

ps：要把 Claude Code 的 hook 玩明白其实挺不容易，调试起来不算很方便

最终我搞定了一种交互式 md 文档人机协作改稿方式，体验还蛮有意思的：

------

旧流程（无 hook）
👤 1. 手动让 CC 生成一份 md 初稿
👤 2. 手动打开 md 文件修改
👤 3. 改完后，再手动跟 CC 说：
"对比一下修改前后的内容，继续优化"
🤖 4. CC 才开始真正干活


问题很明显：流程被拆碎了，人要做很多"解释型劳动"。
------

新流程（hook + md）
🤖 1. CC 按用户要求生成 md 初稿
👤✏️ 2. 自动弹出编辑器，直接在里面改
🤖 3. hook 自动捕捉改动，CC 推断你的修改意图
🤖 4. CC 基于意图完成最终 md


核心变化是：
从「👤 反复解释给 🤖」
→
「🤖 看懂 👤 改了什么，然后接着干」
