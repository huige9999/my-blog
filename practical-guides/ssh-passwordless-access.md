### 原理

```
你的电脑                         云服务器
┌──────────────┐               ┌──────────────┐
│ 私钥（id_rsa）│ ──配对验证──→ │ 公钥（authorized_keys）
└──────────────┘               └──────────────┘
 私钥留在本地，不给任何人          公钥放在服务器上
```

就像一把锁（公钥）和一把钥匙（私钥），锁装在服务器上，钥匙在你手里，配对成功就不用输密码了。

### 操作步骤

#### 1. 本地生成密钥对

```bash
ssh-keygen -t rsa -b 4096
```

一路回车即可，会在 `~/.ssh/` 下生成：

- `id_rsa` — 私钥（不要给任何人）
- `id_rsa.pub` — 公钥（要传到服务器上）

#### 2. 把公钥传到服务器

```bash
ssh-copy-id root@你的服务器IP
```

输入最后一次密码，之后就免密了。

#### 3. 测试

```bash
ssh root@你的服务器IP
```

不再要求输入密码就说明成功了。

### 一句话

生成密钥对，公钥丢服务器，私钥留本地，以后再也不用输密码。
